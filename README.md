# Winrose Kiriswa - Professional Portfolio

A modern, responsive portfolio website showcasing professional experience, skills, and projects.

## Features

- Responsive design that works on all devices
- Modern and clean UI with smooth animations
- Interactive skills and projects sections
- Contact form with database integration
- Professional timeline for experience
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6+)
- PHP 7.4+
- MySQL
- Font Awesome Icons

## Setup Instructions

1. **Database Setup**
   - Create a MySQL database using the script in `database/setup.sql`
   - Update database credentials in `php/contact.php`

2. **Web Server Configuration**
   - Place the project files in your web server directory
   - Ensure PHP and MySQL are properly configured
   - Set appropriate permissions for the PHP files

3. **Customization**
   - Replace placeholder images in the `images` directory
   - Update project information in `js/script.js`
   - Modify content in `index.html` as needed
